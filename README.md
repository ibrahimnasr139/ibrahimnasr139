## 🚀 Featured Projects

### [Waey LMS Platform](https://www.waey.online) — Multi-Tenant SaaS LMS
> *Production · 2025–2026*

A production-grade multi-tenant SaaS Learning Management System where each tenant operates an independent branded learning platform via subdomain architecture.

**Key Engineering Highlights:**
- 🏗 **Multi-Tenant Architecture** — Full subdomain-based tenant isolation with end-to-end payment processing
- 🔐 **Auth & Access Control** — JWT, OTP verification, password reset, invite-based onboarding, and fine-grained RBAC
- 📚 **Education Engine** — Courses, modules, content library, announcements, quizzes, and configurable question banks
- 🌐 **Website Builder Backend** — Per-tenant page/layout/branding management in complete isolation
- 🎥 **Zoom OAuth Integration** — Live session scheduling with configurable settings and automated email notifications
- 📦 **File Upload Pipeline** — Signed video uploads via Bunny.net with processing status tracking
- 💳 **Commercial Layer** — Plans, subscriptions, billing APIs with usage-limit enforcement

**Tech Stack:**
`C#` `ASP.NET Core` `SQL Server` `Entity Framework Core` `Redis` `Hangfire` `Zoom OAuth` `Bunny.net` `Docker` `Clean Architecture` `CQRS`

🔗 **Live:** [www.waey.online](https://www.waey.online)

### [Waey Student Portal](https://students.waey.online) — AI-Powered Gamified LMS
> *Production · 2025–2026*

The student-facing layer of the Waey SaaS platform — an AI-powered gamified learning portal with real-time collaboration and full engagement engine.

**Key Engineering Highlights:**
- 🤖 **AI Study Tools** — Quiz generation, flashcard creation, AI tutor chat, and learning roadmap APIs via LLM integration
- ⚡ **Real-Time Study Rooms** — SignalR-powered live collaborative sessions with presence tracking
- 🏆 **Gamification Engine** — XP accumulation, level progression, badge awarding, streak tracking, and leaderboard APIs
- 🔐 **Passwordless Auth** — Frictionless student access across tenants with identity isolation at the API level
- 📈 **Progress Tracking** — Hierarchical course management with per-module access control aligned to subscription plan
- 👥 **Social Learning** — Peer interaction, discussion APIs, notifications, and announcements infrastructure

**Tech Stack:**
`C#` `ASP.NET Core` `SQL Server` `Entity Framework Core` `SignalR` `Redis` `Hangfire` `LLM Integration` `Clean Architecture` `CQRS`
